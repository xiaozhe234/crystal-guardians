# 晶域守卫者（Web 版）

一个可直接运行的 HTML5 Canvas Roguelike 虚蚀领域冒险游戏原型，无需构建工具、无需联网，双击 `index.html` 即可游玩。
也可以用 Node 起本地静态服务器游玩（零依赖，端口可配置）：`node server.js` 后访问 `http://localhost:8080/`。

## 快速开始
1. 双击打开 `index.html`（推荐 Chrome / Edge）。
2. 主菜单 → 「开始游戏」→ 选择角色 → 进入「虚蚀领域」或「元晶守卫战」。
3. 操作：`WASD/方向键` 移动 · 鼠标瞄准 · `左键` 射击 · `空格` 释放技能 · `E` 交互（交易/拾取武器）· `Q` 切换主副武器 · `Esc/P` 暂停；元晶守卫战另用 `B` 商店、`V` 建造、`K` 作弊菜单。
4. 通关 3 个领域（外层→中层→核心）即胜利；结算获得星晶，可用于解锁更多角色与开启虚蚀因子。
5. 完整规则、游戏元素含义与键位说明见 `docs/游戏规则.md`。

### 本地静态服务器（可选）
```powershell
node server.js                    # 默认端口 8080（含 WebSocket 联机）
node server.js --port 5173        # 指定端口
$env:PORT=5173; node server.js    # 或用环境变量 PORT
```
服务器零依赖、仅用 Node 内置模块；`server.js` 内置 WebSocket 联机服务（`net/game-server.js` 房间大厅 + 自研 RFC 6455 帧实现 `net/ws-frame.js`），端口沿用同一套配置（默认 8080，可用 `--port` / `PORT` 覆盖）。

## 已实现功能
- 大厅：角色选择与星晶解锁（6 角色，各自独立属性/技能）、音效与自动射击设置、本地存档（localStorage）。
- 模式：冒险模式「虚蚀领域」（3 域闯关）+ 无尽模式「元晶守卫战」（守卫元晶抵御蚀潮）。
- 联机：主菜单「联机模式」→ 创建/加入房间（房间大厅），2~4 人合作；服务器权威模拟（约 30Hz 快照同步 + 本地预测），房主选择晶悟、增强效果对全队生效；断线自动返回大厅。
- 虚蚀领域：4×3 网格随机连通房间（生成树+环，每域 6~12 间），包含普通怪房、精英房、BOSS 房、商店、宝箱房、晶泉房；清房开门，全清解锁 BOSS 房，BOSS 死后晶界传送进入下一域。
- 战斗：生命/护甲/能量数值、暴击、火/冰元素（灼烧/减速）、手刀近战、主副武器切换、宠物自动攻击、械晶哨塔等。
- 武器：25 把（碎晶手枪/连射晶弩/晶爆裂管/晶光射线/晶钢斩刃/晶锋长刺/纹弓/燃晶杖/凝晶杖/蚀爆晶珠/晶核转轮机枪/穿域重狙 等），虚蚀领域宝箱、BOSS、商店均可获取。
- 敌人：蚀浆怪、虚翼蝠、蚀射虫、蚀晶炮台、厚甲蚀卫（冲锋）+ 精英变体；3 个多阶段 BOSS（蚀浆之王/重炮蚀塔/虚蚀统帅）。
- 晶悟：清房后三选一（9 种，如晶脉扩张/蚀敌怒化/晶纹速射/晶眼洞察等）。
- 元晶守卫战：喘息期建造 6 类晶防装置（Ⅰ~Ⅵ 级）、晶旅商栈购物、条件型临时增益、永久强化，每 5 潮 BOSS。
- 道具：金币、生命药水、能量药水、武器掉落、可破坏木箱；商人金币交易。
- 生命周期：死亡结算 / 通关结算，发放星晶并写入存档（击杀、通关次数、最佳层数）。

## 目录结构
- `index.html` — 入口（含 `game/js/net.js` 联机客户端）
- `server.js` — 零依赖静态服务器 + WebSocket 联机入口（端口可配置，默认 8080）
- `net/` — 联机服务端（`game-server.js` 房间大厅/权威模拟，`ws-frame.js` WebSocket 帧实现）
- `package.json` — 启动脚本（`npm start`）
- `game/js/` — 全部游戏逻辑（utils/config/audio/save/effects/bullets/weapons/talents/player/enemies/items/dungeon/ui/main）
- `game/css/style.css` — 样式
- `docs/` — 策划文档（功能树形结构、策划需求版）
- `tools/smoke-test.js` — Node 单机冒烟测试（脚本化完整通关 + 技能/武器/死亡/压力测试）
- `tools/net-smoke.js` — 联机冒烟测试（双客户端：建房/加入/开局/移动/敌人AI/射击/房主晶悟）
- `tools/net-render-test.js` — 联机客户端渲染测试（真实快照驱动全 UI 绘制路径）

## 测试
```powershell
node tools/smoke-test.js       # 单机：完整通关 + 技能/武器/死亡
node tools/net-smoke.js        # 联机：双客户端建房/开局/移动/晶悟
node tools/net-render-test.js  # 联机：客户端快照渲染冒烟
```
需安装 [Node.js](https://nodejs.org/)。测试会模拟完整通关（3 域 3 BOSS）、全角色技能、全武器开火、死亡结算与随机压力帧，全部通过后输出 `ALL CHECKS PASSED`。
