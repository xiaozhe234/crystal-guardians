# 晶域守卫者（原创 Roguelike）· 游戏规则

> 本作包含两个模式：**冒险模式 · 虚蚀领域**（第一~五节）与 **无尽模式 · 元晶守卫战**（第六节）。

## 一、游戏目标

1. 进入虚蚀领域，从出生点开始，**逐个房间清怪**推进。
2. 清完当前域的全部战斗房间后，**BOSS 房解锁**；击败 BOSS 后房中出现**晶界传送**。
3. 走进晶界传送进入**下一域**，共 3 域（外层 → 中层 → 核心）。
4. 通关 3 域即**胜利**；生命归零则**失败**结束本局。
5. 结算获得**星晶**（本局金币×2 + 层数奖励 + BOSS 击杀奖励 + 通关奖励），用于在主菜单解锁更多角色、开启虚蚀因子。

## 二、核心循环（一局怎么玩）

1. 出生点就有怪物，**先清怪**（怪物分蚀潮出现，最多 3 潮）。
2. 清空房间后弹出**晶悟三选一**，选一张卡片继续。
3. 房间清空后**门解锁**：门口出现发光通道和箭头，走进去就进入下一间房；角色头顶的**金色箭头**会通过房间寻路，**指向最近一间还没清完怪的房间**（全清后指向 BOSS 房，BOSS 死后指向晶界传送）。
4. **蚀潮机制**：战斗房清完当前一潮后约 **1 秒**，地面出现下一潮怪物的**落脚点**（金色闪烁圆圈），再 **1 秒**后怪物逐个显形并开始攻击；普通房最多 **3 潮**（BOSS 房不分潮），顶部 HUD 显示当前蚀潮。
5. 房间类型随机：普通怪房、精英房、商店、宝箱房、**晶泉房**、BOSS 房。每域共 **6~12 个房间**，其中奖励房（商店+宝箱房）**1~3 个**，随房间总数自适应；房间大小随机变化，不会超大或超小。
6. 商店可用金币买武器/药水；**武器槽已满时购买武器会弹出确认框**，确认后才扣钱并替换当前武器（取消不扣钱）；宝箱房开宝箱；**晶泉房无怪物**，中央泉水触碰一次回复 3 生命 + 30 能量；木箱可以打碎。
7. 全清战斗房 → BOSS 房解锁（门上的锁变绿）→ 击败 BOSS → 走进晶界传送 → 下一域。

## 三、游戏元素代表什么

### 玩家属性（左上角 HUD）
| 图标 | 属性 | 说明 |
| --- | --- | --- |
| ❤ | 生命 | 归 0 即死亡，本局结束 |
| 🛡 | 护甲 | 优先承受伤害，**不会自动回复**，可被晶悟/技能补充 |
| ⚡ | 能量 | 射击与技能消耗，随时间自动回复 |
| 💥 | 暴击 | 概率触发，造成 **2 倍伤害** |
> HUD 里每根条前面都有图标：❤️ 生命 / 🛡️ 护甲 / ⚡ 能量，条右侧显示当前值；底部武器栏会显示每把武器每次射击的**耗能**（如“耗能 2”，0 表示不耗能），技能格也会显示技能耗能。
> - 开启虚蚀因子时，左上角会显示激活的**因子图标与名称**。
> - 测试版**默认解锁全部 6 名角色**，方便直接试玩。
> - 鼠标悬停底部武器槽（或商店界面）会弹出**武器详细属性面板**（类型/伤害/射速/耗能/暴击/特效），方便购买或拾取前对比。

### 资源与道具
| 图标 | 名称 | 说明 |
| --- | --- | --- |
| 🪙 | 金币 | 局内货币，在商店消费 |
| 💎 | 星晶 | 局外货币，结算获得，解锁角色/虚蚀因子 |
| 🧪 | 生命药水 | 回复 3 点生命 |
| 🔵 | 能量药水 | 回复 50 点能量 |
| 📦 | 木箱 | 可打碎，可能掉落金币/药水/武器 |

| --- | --- |

| 黄色 | 商店（与商人按 E 交易） |

### 敌人
| 敌人 | 行为 |
| --- | --- |
| 蚀浆怪 | 缓慢贴近并撞击 |
| 虚翼蝠 | 快速贴近并撞击 |
| 蚀射虫 | 保持距离远程射击 |
| 蚀晶炮台 | 定点连续射击 |
| 厚甲蚀卫 | 蓄力后冲锋 |
| 精英怪 | 更大更肉、伤害更高（头顶金色三角） |
| BOSS | 共 3 个（蚀浆之王 / 重炮蚀塔 / 虚蚀统帅），均有二阶段，死后掉落宝箱+晶界传送 |

### 武器类型
- **远程**：碎晶手枪、连射晶弩、晶爆裂管、晶光射线、超射程晶狙、晶核转轮机枪
- **近战**：晶钢斩刃（扇形挥砍）、晶锋长刺（直线突刺）
- **特殊**：纹弓（按住蓄力）、燃晶杖（灼烧）、凝晶杖（减速）、蚀爆晶珠（范围爆炸）
- 主手/副手双武器位，按 **Q** 切换

### 晶悟（清房后三选一，共 9 种）
晶脉扩张、晶壳强化、晶核容量、蚀敌怒化（伤害+15%）、晶纹速射（攻速+15%）、晶眼洞察（暴击+8%）、晶步疾行、晶兽唤醒、磁力增幅。

## 四、键位操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D 或 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 鼠标左键 | 射击（按住连射；近战为挥砍） |
| 空格 | 释放技能（消耗能量，有冷却） |
| E | 交互：与商人交易 / 拾取掉落武器 |
| Q | 切换主/副武器 |
| Esc / P | 暂停 |
| 暂停菜单 | 继续 / 音效 / 自动射击 / **重新开局**（立即重开一局）/ 返回大厅 |
| Enter | 菜单/结算界面确认 |

## 五、进阶机制

- **虚蚀因子**：角色选择界面可开启，开局随机抽 2 个正面/负面因子（如敌人更强、攻速提升、晶能无竭等）。
- **元素效果**：火焰造成持续灼烧，冰霜减速敌人。
- **宠物**：跟随玩家自动攻击附近敌人。
- **角色技能**：6 名角色技能不同（晶核过载、瞬影步、晶纹雷击、晶泉回涌、召唤晶哨塔、虚蚀突穿），耗能并有冷却。
- **本地存档**：进度（星晶、解锁角色、通关数）保存在浏览器 localStorage 中；测试版存档会强制全部角色可用。

## 六、无尽模式 · 元晶守卫战

核心玩法：守卫世界之核「元晶」，抵御一波波虚蚀者进攻（蚀潮），撑得越久越荣耀。

### 1. 流程循环
1. 进入模式后为**喘息期**（固定 60 秒）：可建造晶防装置、在晶旅商栈购买、强化永久属性。
2. 喘息期结束进入战斗：虚蚀者从多路进攻元晶 / 玩家 / 晶防装置；清空后回到喘息期。
3. 每 5 潮出现一个 BOSS；元晶生命归 0、或玩家耗尽复活次数后判负。
4. 可随时**撤退结算**（右下角按钮，需确认），按当前蚀潮发放奖励并记录最佳蚀潮。

### 2. 晶防装置（建造面板，按 V 打开）
- 6 类装置：**路障**（反伤）、**能量发生器**（回能量）、**机枪炮台**、**火焰炮台**（灼烧）、**治疗装置**（光环回血）、**电磁装置**（范围减速）。
- 每类分 Ⅰ~Ⅵ 级，逐级解锁于第 0 / 5 / 10 / 20 / 30 / 40 潮；高级解锁后低等级自动隐藏（始终显示连续 3 级窗口）。
- 建造面板点击卡片 → 地图选点放置；拆除返还 30% 金币；装置上限随蚀潮提升（6 → 20）。
- 装置生命在喘息期自动恢复 20%。

### 3. 晶旅商栈（按 B 打开）
- 出售武器、生命/能量药水、**元晶修补液**（+10 元晶HP）、**元晶屏障**（抵挡 20 点伤害，持续 2 潮）、**重生十字章**（+1 复活次数）。
- 每次喘息期自动刷出 2 个**临时增益**槽位（每潮限购 1 个）；可花金币刷新（费用逐次 +5，上限 30）。

### 4. 临时增益（条件型，只作用于下一潮）
- **输出**：怒击（HP≤50% 伤害+50%）、狂热（身边 200px 内 ≥3 敌人攻速+60%）、穿甲弹（对精英/Boss 穿透+2 并减速）、嗜血（连续命中 5 次后吸血 10%）。
- **生存**：掩体模式（站装置 120px 内远程伤害-80%）、元晶回春（元晶首次跌破 50% 回复 25%，一次性）。
- **经济**：财源滚滚（本潮击杀金币 ×1.5）。
- **装置协同**：晶防装置超频（已建装置攻速+50% 射程+15%）、炽焰扩散（火焰塔点燃传染 120px）。
- 条件型增益在战斗中实时判定：满足条件生效（图标亮），不满足挂起（图标灰）。

### 5. 永久强化
- 8 项：生命 / 护甲 / 能量 / 伤害 / 暴击 / 射速 / 宠物伤害 / 宠物攻速。
- 每潮喘息期购买次数 = 1 + floor(当前潮 / 5)，费用随等级上涨。

### 6. 其他
- 玩家可复活 2 次；复活次数耗尽后阵亡 5 秒判负。
- 作弊菜单：按 **K** 打开（无敌 / 一击必杀 / 无限能量 / 无限金币 / 调速 / 跳潮）。
