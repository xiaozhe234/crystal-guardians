# 晶域守卫者｜开发进度与需求（已实现为准）

> 本文档以「当前已实现」为第一优先级，逐项列出真实功能与验收要点；
> 「待完善」记录已知缺口；「拓展规划」仅作备忘，随开发逐步补充。

## 一、已实现功能（当前版本）

### 1. 大厅
| 模块 | 说明 | 状态 |
|---|---|---|
| 角色选择 | 6 名角色（属性差异 + 独立技能），星晶解锁（测试版默认全解锁） | ✅ |
| 虚蚀因子 | 角色选择界面开关，开局随机抽 2 个正面/负面因子 | ✅ |
| 设置 | 音效 / BGM / 音量、自动射击 | ✅ |
| 本地存档 | localStorage：星晶、解锁角色、通关数、击杀、最佳层数、最佳蚀潮 | ✅ |

### 2. 冒险模式 · 虚蚀领域
- 三层领域：外层晶簇边境 → 中层蚀影秘境 → 核心虚蚀核心。
- 随机房间：4×3 网格，生成树 + 环路，全图连通；每域 6~12 间；房间大小随机。
- 房间类型：出生点 / 普通 / 精英 / BOSS / 商店 / 宝箱 / 晶泉房。
- 蚀潮机制：战斗房 1~3 潮，落脚点预告后怪物显形。
- 晶悟：清房后三选一（9 种）。
- 武器 25 把；怪物 30+ 种 + 精英变体；BOSS 3 个（蚀浆之王 / 重炮蚀塔 / 虚蚀统帅，均有二阶段）。
- 战斗：生命 / 护甲 / 能量、暴击、灼烧 / 减速 / 中毒、主副武器、宠物、技能。
- 结算：金币 ×2 + 层数 + BOSS + 通关奖励 → 星晶。

### 3. 无尽模式 · 元晶守卫战
- 守卫世界之核「元晶」，蚀潮进攻，每 5 潮生成 BOSS；喘息期固定 60s。
- 晶防装置：6 类 × Ⅰ~Ⅵ 级（路障 / 能量发生器 / 机枪炮台 / 火焰炮台 / 治疗装置 / 电磁装置），建造面板点击放置、可拆除。
- 晶旅商栈：武器 / 生命药水 / 能量药水 / 元晶修补液 / 元晶屏障 / 重生十字章 / 临时增益（刷新费 +5/次，上限 30）。
- 临时增益：9 种条件型 buff，每潮限购 1 个。
- 永久强化：8 项（生命 / 护甲 / 能量 / 伤害 / 暴击 / 射速 / 宠物伤害 / 宠物攻速），每潮购买次数 = 1 + floor(潮/5)。
- 重生 2 次，耗竭后 5s 阵亡；可撤退结算；作弊菜单（K）。

### 4. 联机模式
- 房间大厅：创建 / 加入 / 刷新；2~4 人合作。
- 服务器权威模拟（~30Hz 快照同步 + 本地预测）；房主选晶悟全队生效；断线返回大厅。

### 5. 移动端
- 虚拟摇杆 / 按键、拖拽自定义布局、触控建造、作弊 / 暂停 / 商店等 UI 适配。
