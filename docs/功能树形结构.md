# 晶域守卫者｜功能结构（当前已实现）

> 本结构以当前版本**实际已实现**的系统为准，用于开发同步与需求拆分。
> 规划中、尚未实现的功能统一放在文末「待拓展」小节，后续逐步补齐。

```
晶域守卫者
├── 一、大厅
│   ├── 角色选择
│   │   ├── 6 名角色：晶卫 / 锋影 / 雷纹 / 晶辉 / 械晶 / 暗蚀
│   │   ├── 星晶解锁（测试版默认全部解锁）
│   │   ├── 属性面板：生命 / 护甲 / 能量 / 暴击 / 移速
│   │   └── 独立技能：晶核过载 / 瞬影步 / 晶纹雷击 / 晶泉回涌 / 召唤晶哨塔 / 虚蚀突穿
│   ├── 虚蚀因子开关（6 种因子随机正负 buff）
│   ├── 设置
│   │   ├── 音效 / BGM / 音量
│   │   ├── 自动射击
│   │   └── 本地存档（localStorage）
│   └── 模式入口
│       ├── 冒险模式「虚蚀领域」
│       └── 无尽模式「元晶守卫战」
│
├── 二、冒险模式 · 虚蚀领域
│   ├── 三层领域
│   │   ├── 外层-晶簇边境
│   │   ├── 中层-蚀影秘境
│   │   └── 核心-虚蚀核心
│   ├── 房间生成
│   │   ├── 4×3 网格，生成树 + 环路，保证全图连通
│   │   ├── 每域 6~12 间（随层数递增）
│   │   ├── 房间大小随机（不固定、不超大/超小）
│   │   └── 房间类型：出生点 / 普通房 / 精英房 / BOSS房 / 商店 / 宝箱房 / 晶泉房
│   ├── 蚀潮机制
│   │   ├── 战斗房最多 3 潮
│   │   ├── 落脚点预告（金色圆圈）→ 怪物显形攻击
│   │   └── HUD 显示当前蚀潮
│   ├── 晶悟系统（清房后三选一，9 种）
│   │   ├── 晶脉扩张 / 晶壳强化 / 晶核容量
│   │   ├── 蚀敌怒化 / 晶纹速射 / 晶眼洞察
│   │   ├── 晶步疾行 / 晶兽唤醒 / 磁力增幅
│   ├── 角色战斗
│   │   ├── 移动 / 瞄准 / 射击（按住连射）
│   │   ├── 近战手刀（挥砍 / 突刺）
│   │   ├── 技能释放（空格，耗能 + 冷却）
│   │   ├── 主副武器切换（Q）
│   │   ├── 暴击（2 倍伤害）
│   │   └── 元素效果：灼烧 / 减速 / 中毒
│   ├── 武器系统（25 把）
│   │   ├── 类型：单发 / 自动 / 近战 / 蓄力弓 / 法杖 / AOE / 穿透 / 击退
│   │   ├── 获取：宝箱 / 商店 / BOSS / 怪物掉落
│   │   └── 双武器位，可替换
│   ├── 怪物与 BOSS
│   │   ├── 30+ 种虚蚀者怪物（分三层 + 元晶守卫战专属）
│   │   ├── 精英变体（更大更肉、伤害更高）
│   │   └── 3 个 BOSS（蚀浆之王 / 重炮蚀塔 / 虚蚀统帅），均有二阶段
│   ├── 宠物与盟友
│   │   ├── 宠物自动攻击
│   │   └── 械晶技能召唤晶哨塔
│   ├── 交互
│   │   ├── 商店交易（E）
│   │   ├── 宝箱 / 木箱
│   │   ├── 晶泉房（回复 3 生命 + 30 能量，每房一次）
│   │   └── 晶界传送（进入下一域）
│   └── 结算
│       ├── 金币 → 星晶（×2 + 层数 + BOSS + 通关奖励）
│       └── 存档：通关数 / 击杀 / 最佳层数
│
├── 三、无尽模式 · 元晶守卫战
│   ├── 核心目标：守卫世界之核「元晶」，抵御一波波蚀潮
│   ├── 蚀潮与喘息期
│   │   ├── 战斗阶段：怪物进攻元晶 / 玩家 / 晶防装置
│   │   ├── 每 5 潮生成 BOSS
│   │   └── 喘息期固定 60s（建造 / 购买 / 强化）
│   ├── 晶防装置（6 类 × Ⅰ~Ⅵ 级）
│   │   ├── 路障（反伤）、能量发生器、机枪炮台
│   │   ├── 火焰炮台（灼烧）、治疗装置（光环）、电磁装置（EMP 减速）
│   │   ├── 等级解锁：Ⅰ(0) Ⅱ(5) Ⅲ(10) Ⅳ(20) Ⅴ(30) Ⅵ(40) 潮
│   │   ├── 建造面板（商店式网格，点击放置）
│   │   ├── 装置上限随蚀潮提升（6 → 20）
│   │   └── 拆除（30% 退款）
│   ├── 晶旅商栈
│   │   ├── 武器 / 生命药水 / 能量药水
│   │   ├── 元晶修补液 / 元晶屏障 / 重生十字章
│   │   ├── 临时增益（2 个槽位，每潮限购 1 个）
│   │   └── 刷新机制（费用逐次 +5，上限 30）
│   ├── 临时增益（9 种条件型 buff）
│   │   ├── 输出：怒击 / 狂热 / 穿甲弹 / 嗜血
│   │   ├── 生存：掩体模式 / 元晶回春
│   │   ├── 经济：财源滚滚
│   │   └── 装置协同：晶防装置超频 / 炽焰扩散
│   ├── 永久强化（8 项）
│   │   ├── 生命 / 护甲 / 能量 / 伤害 / 暴击 / 射速 / 宠物伤害 / 宠物攻速
│   │   └── 每潮购买次数 = 1 + floor(潮/5)
│   ├── 重生与阵亡（2 次复活，耗竭后 5s 失败）
│   ├── 撤退结算（右下角，确认后按波次结算）
│   └── 作弊菜单（K，含跳潮）
│
├── 四、联机模式
│   ├── 房间大厅：创建 / 加入 / 刷新房间列表
│   ├── 2~4 人合作
│   ├── 服务器权威模拟（~30Hz 快照同步 + 本地预测）
│   ├── 房主选择晶悟，全队生效
│   └── 断线自动返回大厅
│
├── 五、移动端适配
│   ├── 虚拟摇杆 + 按键
│   ├── 拖拽自定义按钮布局（布局版本化）
│   ├── 触控放置晶防装置
│   └── 作弊 / 暂停 / 商店等 UI 适配
│
└── 六、测试与工具
    ├── tools/smoke-test.js —— 单机冒烟（通关 / 技能 / 武器 / 死亡 / 压力）
    ├── tools/net-smoke.js —— 联机冒烟（建房 / 加入 / 移动 / 射击 / 晶悟）
    └── tools/net-render-test.js —— 联机快照渲染冒烟
```
